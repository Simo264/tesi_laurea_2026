## Come usare questo template
- Esamina la struttura delle cartelle per capire come è organizzato il progetto.
- Leggi i commenti all'inizio del file bibliography.bib.
- Guarda gli esempi presenti nel template; ogni capitolo contiene indicazioni utili per scrivere la tesi in modo efficace.
- Inizia a scrivere aggiungendo le citazioni man mano. Non rimandare la compilazione della bibliografia alla fine.
- Questo template non fornisce indicazioni su come strutturare i contenuti della tesi. Rivolgiti direttamente al tuo supervisore.

## Standard di scrittura
- Usa una terminologia e una notazione coerenti, senza modificarle nel corso della tesi.
- Introduci figure e tabelle nel testo principale ed esplica ciò che mostrano. Fai sempre riferimento a ogni immagine, tabella o elemento simile usando \ref{}.
- Utilizza fonti di qualità e affidabili.
